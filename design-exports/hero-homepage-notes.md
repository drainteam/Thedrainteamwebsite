# Homepage Hero Figma Handoff

Frame: 1440 × 880 px.

## Included

- Current locally rendered hero background and dark gradient treatment
- Current overlaid desktop navigation visible in the rendered reference
- Hero title and subtitle
- Request a Quote and View Drainage Services buttons

## Files

- `hero-homepage-current.png` is the authoritative visual reference captured from the current local homepage at 1440 px wide.
- `hero-homepage-current.svg` is the editable Figma-oriented version. Text remains text and the background photograph is embedded, so no remote assets are required.

## Bottom strip

The current Hero no longer contains a bottom stats strip. The red scrolling ticker and trust bar below it are separate page sections, so a `hero-homepage-current-with-strip.png` export was not created.

## Font note

The live site uses Barlow Condensed and Montserrat. To avoid remote-font dependencies, the SVG uses Impact/Arial Black and Arial/Helvetica fallbacks. Use Barlow Condensed and Montserrat in Figma when available for the closest match. The PNG preserves the browser-rendered web fonts and should be treated as the visual reference.
